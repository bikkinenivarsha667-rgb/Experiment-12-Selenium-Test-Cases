# Selenium Testing of a Containerized Application

## Objective
To develop and execute automated test cases for a Docker and Kubernetes application using Selenium WebDriver and JUnit.

## Tools Used
- Java
- Maven
- Selenium WebDriver
- JUnit 4
- Docker
- Kubernetes
- Google Chrome

## Test Cases
1. Verify that the application home page loads with the expected title and heading.
2. Verify that the application displays the expected Kubernetes message.

## Execution
Run the tests using:

mvn clean test
